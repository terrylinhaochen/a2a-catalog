Scope, limits & pricing +

Uses the sources, filters and collection limits in a saved CrowdListen workflow. Measured growth needs comparable time windows; likes-to-followers virality needs follower observations.

For the live billed pilot, the task quote uses 4× recorded provider cost, with a maximum $2 card authorization. Totals below $0.50 are waived. Paid execution requires your exact approval and card authorization. Sponsored tasks are identified separately.

Connect with Codex

Remote MCP

Register the hosted connection:

codex mcp add skillshare \
  --url https://crowdlisten-skills-api.vercel.app/skillshare/api/mcp \
  --bearer-token-env-var SKILLSHARE_ACCESS_TOKEN
A connection also needs authentication.

Supply your CrowdListen customer session through the harness’s protected environment as SKILLSHARE_ACCESS_TOKEN, then start a fresh Codex session. The command alone does not sign you in. Never paste the token into chat.

Already using the CrowdListen CLI? The existing-login adapter can reuse that session. Automatic OAuth connection is not yet available in this pilot.
